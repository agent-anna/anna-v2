## Renaming

Run `python3 rename_pages.py` to automatically rename all `PAGE-*.md` files to zero-padded format (`PAGE-001.md` – `PAGE-200.md`).

After running, this manifest will match the actual file order perfectly.

The script will also report any missing page numbers. If a `PAGE-150.md` is missing, we'll need to create it together. But everything else is ready.
