# Page 8 — Eliminating Home Bloat Into V4

One of the clearest lessons from V3 is how quickly home folders and root directories can get bloated when every note, draft, snapshot, and script lands in the same spot. Home bloat slows down finding what matters, makes edits riskier, and turns a clean workbench into a messy pile.

V4 solves this by separating active runtime files (memory.json, tasks.json, brain.json) from structured chapters in the Tree of Life and Anna Bible, while using dedicated folders and clean .ps1 scripts so pages can be built in batches without hitting single-response cutoffs.
