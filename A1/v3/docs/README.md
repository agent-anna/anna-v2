# Agent Anna V3 — From Code to Conduct

> **A living blueprint for building an autonomous, grounded AI companion without losing sight of who you are.**

## Why This Book Exists
Most AI systems fail because they pile everything into one fragile front-end script, guess when data is missing, and bury the human operator in noise. **Agent Anna V3 (AA01)** separates **thought** from **action**:

1. **The Cockpit (`A1/v3/anna-v3-ui.js`)**: Fast, voice-first, calm, single-shot interface. Zero CORS hacks, zero code read aloud, zero blind guessing.
2. **The Workers (`.github/workflows/`)**: Headless Chromium scrapers, scheduled vault digests, and self-documenting Tree of Life builders running cleanly on GitHub runners.
3. **The Living Book (`A1/v3/docs/`)**: Every chapter documents real, working functions—and updating this book triggers the system to verify and map itself.
